# Preserved Master Specification

It is preserved as the architecture/product/security/migration/production source of truth. Do not edit it merely to record implementation progress; use `SANFOOTBALL_IMPLEMENTATION_STATUS.md` and approved ADRs for that.

Concern agents should read only the sections listed in their `Master-spec source map` by default. Additional sections may be consulted when a concrete dependency, conflict, security issue, migration issue, or architectural ambiguity requires them.

The adjacent `.sha256` file can be used to verify that this preserved copy has not been altered from the original package master specification.
